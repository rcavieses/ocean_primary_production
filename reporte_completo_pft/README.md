# Reporte Completo - Producción Primaria del Golfo de California

## Cómo visualizar

1. Abra el archivo `index.html` en cualquier navegador web moderno (Chrome, Firefox, Edge, Safari).
2. No requiere conexión a internet — todos los recursos (CSS, JavaScript, fuentes, figuras) están incluidos localmente.

## Contenido

- **index.html** — Reporte principal con 20 secciones de análisis:
  - Composición de grupos funcionales (PFTs)
  - Mapas de promedios y diferencias quinquenales
  - Series de tiempo con índices climáticos (MEI, Niño 3.4, PDO)
  - Análisis estacional y latitudinal
  - Descomposición STL y eventos extremos
  - Análisis de Fourier (ciclos dominantes)
  - Modelos HMM de cambio de régimen
  - Métodos alternativos de detección de extremos
  - Correlación cruzada con permutaciones
  - Causalidad de Granger
  - Correlación canónica (CCA)
  - Regresión segmentada (piecewise)
  - Extremos conjuntos biomasa-clima
  - Análisis de profundidad y abundancia
  - Comparación satelital vs in-situ
  - Series de tiempo in-situ primarias
- **reporte_inferencial.html** — Descripción metodológica de los análisis inferenciales
- **figuras/** — 316 figuras (PNG estáticas + HTML interactivas con Plotly)
- **css/** — Bootstrap 5.1.3 y Font Awesome 6.0.0
- **js/** — Bootstrap Bundle JS
- **webfonts/** — Fuentes Font Awesome para iconos

## Navegación

- Use la barra lateral izquierda para navegar entre secciones.
- Dentro de cada sección, use los botones ◀ ▶ o las flechas del teclado para recorrer las figuras.
- Las figuras interactivas (Plotly) permiten zoom, pan y exportación.

## Requisitos

- Navegador web moderno (2020+)
- Sin dependencias externas
